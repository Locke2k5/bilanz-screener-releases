# Bilanz-Screener – Downloads

Hier gibt es den Installer des Bilanz-Screeners für Windows 10 und 11. Der Quellcode liegt nicht in diesem Repository.

## Herunterladen

Rechts auf dieser Seite unter **Releases** die neueste Version öffnen und die Datei `BilanzScreener-Setup-…exe` herunterladen.

## Windows-Warnung beim Start des Installers

Der Installer ist nicht digital signiert. Windows zeigt deshalb „Der Computer wurde durch Windows geschützt“.
Auf **Weitere Informationen** klicken, dann auf **Trotzdem ausführen**.
Die Release-Notizen enthalten die SHA-256-Prüfsumme und einen Link zur Virenprüfung bei VirusTotal.
